## Project Overview
ProfileListApp is an Android application developed as part of MAD302 Lab 1.  
The application allows users to enter a person's **name and age**, store the information as profiles, and display the profiles dynamically on the screen.

The purpose of this lab is to practice Android UI components, Kotlin programming, lifecycle methods, and proper project documentation and version control using GitHub.

## Application Features
- Input fields to enter Name and Age
- Add profile button to store user data
- Profiles stored in a mutable list
- Display profiles dynamically in the app
- Activity lifecycle logging implemented
- Clean and simple user interface
- Edge-to-edge layout support

## Technologies Used
- Kotlin Programming Language
- Android Studio
- Android SDK
- GitHub for version control

## Application Workflow
1. User enters name and age.
2. User clicks **Add Profile** button.
3. Profile object is created.
4. Profile is added to the list.
5. Profiles are displayed on the screen.
6. Input fields are cleared for next entry.
